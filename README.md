# Sobre o projeto

Este projeto mostra uma tela inicial e em seguida apresenta uma ViewPage contendo Screens informativos que podem ser passados facilmente pelo usuário. Com isso após a 1º interação com a aplicação o usúario entende qual vem a ser o objetivo do mesmo.
